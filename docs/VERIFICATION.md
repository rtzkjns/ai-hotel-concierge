# Живая верификация бота (end-to-end, не только юнит-тесты)

Все ключевые гостевые сценарии прогнаны вживую через WhatsApp-sandbox (реальный сервер +
реальный движок + реальный Claude), часть — на живых данных Exely (property 801, Алматы).
Дата прогона: автономная сессия 2026-07-18.

| Сценарий | Результат | Что подтверждено |
|---|---|---|
| Бронь (многоходовая) | ✅ | Живая цена Exely (147 050 ₸ на 10–13 авг) → сбор данных → подтверждение → персональная ссылка на оплату. Поймали и починили deadlock на фамилии. |
| Кросс-отель в одном чате | ✅ | Гость в чате Алматы спросил про Астану → бот остался в чате, выдал категории Астаны из обогащённой KB, НЕ отфутболил на телефон. |
| MICE (конференц-заявка) | ✅ | Собрал даты/людей/бюджет/контакт → staff-alert (ПД замаскированы) → подтверждение гостю. |
| Жалоба → эскалация | ✅ | Сначала деэскалация, потом хендофф на «дайте человека»; staff-alert (ПД замаскированы) + «сотрудник подключится в этом же чате». |
| Бронь на казахском | ✅ | Диалог целиком на казахском, доходит до подтверждения. |
| Голосовое сообщение | ✅ | audio → фолбэк «не смог прослушать, напишите текстом» (баг мёртвой тишины исправлен). |
| Промокод | ✅ | Честно «проверки в реальном времени нет», направляет на кнопку «Ввести промокод», без переобещаний; зеркалит «ты». |

Сквозная безопасность подтверждена в каждом staff-alert: телефоны и id гостей замаскированы
(`whatsapp:••••|••••`, `+7 7•• ••• •• NN`). Честность подтверждена: бот не выдумывает цены/
скидки/политику, честно называется ботом, максимально оттягивает эскалацию.

Каналы: WhatsApp и Instagram — оба мульти-аккаунтные (все 3 отеля маршрутизируются по номеру /
IG-аккаунту), веб-виджет и Telegram работают. Мультикабинетный Exely: Алматы — живые данные,
Астана/Park — заглушка до их кредов, включаются из конфига.

Автоматические ворота: 220 юнит-тестов + typecheck зелёные; эвал-батарея 39 сценариев,
стабильно 95–100% по раундам, все критичные по безопасности — каждый прогон.

Что НЕ проверено вживую (физически требует внешних доступов): реальная отправка через Meta
(нужен токен), создание брони в Edelweiss через Reservation API (нужен scope, сейчас 403),
живые данные Астаны/Park (нужны их кабинеты Exely). Всё это — go-live, код готов и ждёт ключей.
