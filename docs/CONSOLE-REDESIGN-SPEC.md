## 2.5 Поллинг — чинится, а не выкидывается

`REFRESH_SCRIPT` (`routes.ts:150`) сейчас каждые 5 с перетирает `innerHTML` у `#live` на **шести** страницах. Из-за этого открытый `<select>` статуса MICE (`routes.ts:771`, внутри `#live`) схлопывается каждые 5 секунд.

Новые правила (в `app.v1.js`):
1. Автообновление **только на `/console` (Входящие) и на экране диалога**. На «Заявках», «Знаниях», «Итогах» его нет вообще.
2. Интервал 10 с; при `document.hidden` — полная остановка, при возврате фокуса — один немедленный опрос.
3. **Не подменять**, если `document.getElementById('live').contains(document.activeElement)`.
4. Сравнивать хэш `next.innerHTML` со старым; равны — не трогать DOM.
5. В диалоге: сохранять `scrollTop`; автоскролл вниз только если пользователь был у дна (`scrollHeight - scrollTop - clientHeight < 80`), иначе показывать пилюлю «↓ новое сообщение» над композером.
6. Писать счётчик ожидающих в `document.title` → `(3) Входящие · Kazzhol`.

Срезанный угол показывает направление — это работа, а не украшение. Префикс `[менеджер] ` в UI **не печатается** (только подпись). Между сменой говорящего — 16px, между днями — линия с датой по центру 12px `--text-3` («Сегодня» / «12 августа»).

**Композер (sticky bottom):**
```css

  border-top:1px solid var(--border);box-shadow:0 -1px 2px rgba(18,24,31,.05);
  padding:12px 16px max(12px,env(safe-area-inset-bottom));display:flex;gap:8px;align-items:flex-end;}
```

- `<textarea>` вместо однострочного `<input type="text">` (`routes.ts:400`), авторост 1→6 строк по `scrollHeight`.
- Enter — отправить, Shift+Enter — перенос (десктоп). На телефоне Enter = перенос, отправка кнопкой 44×44.
- На submit: кнопка → «Отправляю…» + `disabled` + `aria-busy` (сейчас двойной тап = **два сообщения гостю**); в ленту вставляется оптимистичный пузырь `opacity:.5` — маскирует 300–800 мс до редиректа.
- **Готовых быстрых ответов в v1 нет.** Три захардкоженные фразы — чужой тон голоса в переписке с гостем. Возвращаем, когда их можно будет редактировать в «Знания → Как говорить».

**Ошибка доставки — inline, страница не меняется.** Сейчас `routes.ts:446–457` отдаёт отдельную страницу «Не доставлено», и набранный текст исчезает. Становится: POST `/console/chats/:id/send` при `!result.ok` делает `redirect(chatUrl + '?err=<код>&draft=1')`, черновик восстанавливается из `sessionStorage`, над композером — баннер `--err-*`: «Не доставлено: истекло окно WhatsApp в 24 часа» + ghost-кнопка «Попробовать снова». **Три вещи, требующие решения владельца до фазы 1:**
1. **Маскировка переписки для не-admin** (`maskFor`, `routes.ts:317,380`): ресепшн видит замазанный номер и не может ни перезвонить, ни найти бронь в Exely — `tel:`-ссылка ведёт в никуда. Предложение: снимать маску **только внутри диалога, который сотрудник взял на себя** (`takenBy === staff.login`); в списках и логах маска остаётся. Это решение по ПД, молча его менять нельзя.
2. **Telegram-уведомление уже работает** (`engine.ts:702`) — добавить в текст ссылку `https://<host>/console/chats/<id>`. 3 строки, и это единственное, что реально сокращает время реакции с 15 минут до 30 секунд; редизайн этого не заменяет.
3. Порог «просрочено» — 20 минут (не 10): проверить на реальной ночной смене и подкрутить одним числом.
