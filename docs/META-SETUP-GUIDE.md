# Meta Business: полный гайд — что вытащить и как (для бота Kazzhol)

Цель: получить 7 значений (таблица в конце), после которых WhatsApp + Instagram каналы бота
заводятся без участия отеля. Написано для человека, который Meta Business видит впервые.

## Карта местности: три разных сайта Meta

| Сайт | Что это | Что там делаем |
|---|---|---|
| **business.facebook.com** | Бизнес-портфолио (Business Manager) — «юрлицо» в мире Meta, владеет страницами/номерами/приложениями | Доступы, верификация, системный пользователь, токен |
| **developers.facebook.com** | Кабинет разработчика — здесь живёт «приложение» (техническая обвязка API) | Создать приложение, App Secret, продукт WhatsApp |
| **business.facebook.com/wa/manage** | WhatsApp Manager — управление номерами WABA | Добавить номера, взять phone_number_id |

Всё связано так: **Портфолио → владеет Приложением → у приложения продукт WhatsApp →
внутри WABA (WhatsApp Business Account) → в нём номера отелей**.

## Этап 1. Доступ и верификация (делает владелец/маркетолог отелей)

1. Найти, есть ли у отелей бизнес-портфолио: тот, кто управляет Инстаграмами отелей, заходит
   на business.facebook.com. Если портфолио есть — НЕ создавать новое (Инстаграмы уже привязаны
   к нему, терять связку нельзя). Если нет — «Создать аккаунт» (название: Kazzhol Hotels,
   рабочая почта на домене отеля).
2. Добавить нашего разработчика админом: **business.facebook.com → Настройки (⚙) → Пользователи
   → Люди → Пригласить людей → email → доступ «Администратор» (полный)**.
3. Запустить верификацию юрлица: **Настройки → Центр безопасности → Верификация бизнеса →
   Начать**. Понадобится: свидетельство о регистрации ТОО (для Алматы — ТОО «МАК-СЕРВИС ЛТД»,
   БИН 040640004843), адрес, телефон, сайт kazzhol.com, почта на домене (не gmail).
   Срок: от 2 дней до 2 недель. ⚠️ Это самый долгий пункт — запускать первым.

Всё остальное ниже могу сделать я сам после пункта 2. Но если делаете сами — вот как.

## Этап 2. Приложение

1. **developers.facebook.com → My Apps → Create App**.
2. Use case: **Other** → тип **Business** → Next.
3. Имя: `Kazzhol AI Bot`, контактный email, в поле Business portfolio выбрать портфолио отелей.
4. Create app.

## Этап 3. Продукт WhatsApp + тестовый номер

1. В приложении: Dashboard → «Add products» → **WhatsApp → Set up**.
2. Выбрать бизнес-портфолио → Meta автоматически создаст **WABA** (WhatsApp Business Account).
3. Открыть **WhatsApp → API Setup**: там сразу есть **бесплатный тестовый номер** —
   с ним можно демонстрировать бота в настоящем WhatsApp ещё до верификации
   (ограничение: писать можно только на 5 заранее добавленных номеров).

## Этап 4. Реальные номера отелей (после верификации бизнеса)

⚠️ Главное: при подключении номер **отвязывается от приложения WhatsApp на телефоне**.
История чатов останется в телефоне, но отвечать оттуда будет нельзя — входящие пойдут в бота,
менеджеры отвечают через нашу консоль. Предупредить менеджеров заранее.

Для каждого номера (+7 708 709 3000 Алматы, +7 776 412 6353 Астана, +7 708 906 0661 Park):

1. Если номер сейчас используется в обычном WhatsApp/WhatsApp Business app: на телефоне
   **WhatsApp → Настройки → Аккаунт → Удалить аккаунт** (да, звучит страшно — это штатная
   процедура миграции номера в API; чаты предварительно можно экспортировать).
2. **WhatsApp Manager (business.facebook.com/wa/manage) → выбрать WABA → Номера телефонов →
   Добавить номер**: ввести номер → выбрать SMS или звонок → ввести код (нужен человек с
   симкой, 2 минуты).
3. Display name (имя, которое видит гость): «Hotel Kazzhol Almaty» и т.п. — Meta проверяет
   его на соответствие бизнесу (обычно часы, иногда до 2 дней).

## Этап 5. phone_number_id (по одному на номер)

**Приложение → WhatsApp → API Setup → выпадающий список «From»**: под каждым номером написан
`Phone number ID` (длинное число, НЕ сам телефон). Либо: WhatsApp Manager → Номера → номер →
вкладка с ID. Скопировать **все три** и подписать, какой чей.

## Этап 6. Постоянный токен (самое важное и самое неочевидное)

Токен из API Setup живёт 24 часа — он НЕ подходит. Нужен вечный токен системного пользователя:

1. **business.facebook.com → Настройки (⚙) → Пользователи → Системные пользователи →
   Добавить**: имя `kazzhol-bot`, роль **Администратор**.
2. Выдать ему приложение: выбрать системного пользователя → **Добавить активы → Приложения →
   Kazzhol AI Bot → Полный доступ (Manage app)** → Сохранить.
3. Там же: **Сгенерировать токен** → выбрать приложение → срок действия: **Never (Бессрочно)**
   → отметить права:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`
   - (для Instagram ещё: `instagram_basic`, `instagram_manage_messages`, `pages_manage_metadata`,
     `pages_messaging`)
4. **Скопировать токен сразу** — он показывается один раз. Это пароль: не слать в общие чаты.

## Этап 7. App Secret

**developers.facebook.com → приложение → App settings → Basic → App secret → Show** (спросит
пароль от Facebook). Скопировать.

## Этап 8. Webhook (делаю я, ничего присылать не надо)

Для справки: Приложение → WhatsApp → Configuration → Webhook: Callback URL
`https://<домен бота>/webhooks/whatsapp`, Verify token — строка, которую мы сами придумали
(она же в конфиге бота), подписка на поле **messages**. Настраивается после появления сервера.

## Этап 9. Instagram Direct (вторая волна, тот же аккаунт)

1. Каждый IG-аккаунт отеля должен быть **Professional (Business)** и привязан к Facebook-странице
   отеля, а страница — к портфолио (Настройки → Аккаунты → Страницы / Аккаунты Instagram).
2. В самом приложении Instagram на телефоне: **Настройки → Сообщения и ответы на истории →
   Разрешить доступ к сообщениям (Connected tools)** — включить. Без этого API не видит директ.
3. В приложении Meta: Add product → **Messenger → Instagram settings** (или продукт Instagram),
   привязать аккаунты.
4. Мне нужны: **ID трёх IG-аккаунтов** (покажу где взять, когда дойдём — можно через
   Graph Explorer, я вытащу сам при наличии токена из Этапа 6 с IG-правами).
