# Статус автономной сессии (2026-07-17)

Что удалось продвинуть без доступа к Meta и к чужим кабинетам Exely, и что осталось жёстко
заблокировано на данных, которые может дать только пользователь/отель.

## Сделано автономно

- **Проверено:** текущие Exely-ключи открывают ТОЛЬКО property 801 (Алматы) — `/api/content/v1/properties`
  вернул один id. Значит Астана и Park Almaty = отдельные кабинеты Exely (отдельные креды+эквайринг).
- **Предзаведена мультикабинетная конфигурация** (`buildExelyCabinets`): креды и property_id каждого
  отеля читаются из env (`EXELY_ASTANA_*`, `EXELY_PARK_ALMATY_*`), back-compat со старым одиночным
  кабинетом. 14/14 тестов конфига. → когда придут креды отелей, это config-drop-in.
- **Деплой-комплект под ключ:** `deploy/Caddyfile` (HTTPS/TLS 1.2+), `deploy/kazzhol-bot.service`
  (systemd, автозапуск/рестарт под SLA), `deploy/deploy.sh` (одна команда на свежем VPS).
- **.env.example** дополнен всеми переменными (Meta, кабинеты, консоль, интеграции).
- (в работе, параллельные агенты) WhatsApp end-to-end sandbox + расширение эвал-батареи до
  manager-grade.

## Жёсткие блокеры — только пользователь может снять

1. **Gmail-токен истёк** — не могу проверить почту `kza200710@gmail.com` на приглашение в Meta.
   Нужна повторная авторизация Gmail-интеграции в интерфейсе. Это единственный способ узнать,
   пришло ли приглашение.
2. **Meta API недоступны без токена.** «Вытянуть апишки Меты» технически невозможно, пока не
   существует доступа: WhatsApp/Instagram Graph API требуют токен системного пользователя из
   бизнес-портфолио отеля, а он появляется только ПОСЛЕ верификации юрлица + принятия приглашения.
   Нельзя обойти или подделать — это не наш аккаунт. Код каналов готов и ждёт токена (см. sandbox).
3. **Exely Reservation scope (403)** — включается только в экстранете отеля (2FA-вход человека).
   Обходить 2FA нельзя (ToS/безопасность). До включения бронь идёт через персональную ссылку.
4. **Креды Exely Астаны и Park Almaty** — отдельные кабинеты, выдаёт отель. Без них живые
   цены этих двух отелей на заглушке (Алматы — живые).

## Что можно сделать в момент получения данных (оценка из прошлого расчёта)

- Приглашение Meta + токен → подключение WhatsApp Алматы и первый живой диалог: ~1 рабочий день.
- Reservation scope → бронь прямо в Edelweiss.
- Креды Астаны/Park → живые данные всех трёх (config-drop-in).
- Полный запуск (3 отеля + WhatsApp + Instagram + голосовые): ~2 недели с пилотом.
