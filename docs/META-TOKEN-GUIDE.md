# Как получить токен WhatsApp Cloud API для Kazzhol (WABA 1363377080731255, +7 708 709 3000)

## 1. Вердикт (коротко и честно)

Да — если аккаунт Facebook (wibzal.m, kza200710@gmail.com) действительно имеет **«полный доступ» к бизнес-портфелю Kazzhol**, то существует **прямой путь без всякого «партнёрского шаринга»**:

> Создать своё приложение внутри портфеля Kazzhol → добавить продукт WhatsApp → выпустить токен.

Ошибка **«достигнуто максимальное число партнёров»** к этому пути **не относится** — это отдельный тупик про раздачу WABA другому бизнесу, вам он не нужен. Забудьте про вкладку «Партнёры».

**Весь исход решает ОДИН вопрос:**

> **WABA 1363377080731255 принадлежит (owned) портфелю Kazzhol — или она лишь «расшарена» (shared-in) в него от другого бизнеса/подрядчика?**

- **Если WABA принадлежит Kazzhol** → прямой путь работает на 100%, никакой App Review, никаких партнёров. Это почти наверняка ваш случай (вы её видите и админите).
- **Если WABA лишь расшарена** (владелец — старый подрядчик/BSP) → есть два подслучая:
  - WABA **всё же видна** в ваших «Аккаунтах WhatsApp» → токен через **системного пользователя** обычно **всё равно выпускается и работает** на этот номер (проверено в разборе). Пробуйте.
  - WABA **вообще не видна** у вас как ресурс → самостоятельно **никак**; нужен владелец (см. раздел 6, минимальный запрос к Бернер/подрядчику).

Сначала сделайте диагностику из раздела 4 — она за 1 минуту говорит, какой у вас случай.

## 2. ОСНОВНОЙ путь (делать под аккаунтом Facebook)

Важно: **всё делаем в браузере, где вы вошли под аккаунтом Facebook** (не Instagram — Instagram-вход физически не пускает на developers.facebook.com, это нормально).

### Часть A. Создать приложение внутри портфеля Kazzhol

1. Откройте **developers.facebook.com** → войдите под аккаунтом Facebook (kza200710@gmail.com). Если попросит «регистрацию разработчика» — пройдите её (подтверждение телефона/почты).
2. **My Apps** (Мои приложения) → **Create App** (Создать приложение).
3. Введите название (например `kazzhol-bot`) и контактный email → **Next**.
4. На шаге выбора сценария выберите **«Connect with customers through WhatsApp»** (в старом интерфейсе: тип **«Business»**, потом добавите продукт WhatsApp) → **Next**.
5. **САМЫЙ ВАЖНЫЙ ШАГ.** Когда попросят выбрать бизнес-портфель — выберите **существующий портфель Kazzhol** (тот, что владеет WABA 1363377080731255). **НЕ создавайте новый портфель** — иначе приложение не увидит вашу реальную WABA и номер.
6. **Create app** (может снова спросить пароль).

> Если в выпадающем списке портфель Kazzhol **не появился** — значит аккаунт Facebook на самом деле ещё не член портфеля. Исправить: business.facebook.com/settings → **Пользователи → Люди** → убедиться, что этот FB-аккаунт есть со статусом **Full control / Админ**. Если нет — существующий админ должен его добавить.

### Часть B. Открыть WhatsApp и увидеть номер

7. В левом меню приложения → **WhatsApp → API Setup** (может называться Quickstart / Getting Started).
8. На панели:
   - **Temporary access token** (вверху, начинается на `EAAG…`, живёт ~23 часа) — для одного теста.
   - **From** (выпадающий список номеров) — выберите реальный **+7 708 709 3000**. Если его нет, а стоит тестовый номер Meta — переходите к системному пользователю (Часть C), там номер подтянется через привязку WABA.
   - **Phone number ID** — числовой ID под номером. **Это и нужно боту** (это НЕ сам номер +7708…).
   - **WhatsApp Business Account ID** — должен быть **1363377080731255**.

### Часть C. Постоянный токен (для боевого бота — обязательно)

Временный токен на 24 часа для бота **не годится**. Делаем «системного пользователя» — его токен можно поставить «Никогда не истекает».

9. Откройте **business.facebook.com/settings** → сверху слева выберите портфель **Kazzhol**.
10. Убедитесь, что приложение из части A видно в **Аккаунты → Приложения**. Если списка нет — **Добавить → Добавить приложение → вставить App ID**. (Если тут пусто — именно поэтому кнопка «Создать токен» серая и пишет «сначала добавьте приложение».)
11. **Пользователи → Системные пользователи → Добавить** → имя `kazzhol-bot`, роль **Admin (Админ)** → создать.
12. Выберите этого системного пользователя → **Назначить активы (Assign assets)**:
    - вкладка **Приложения** → ваше приложение → включить **Управление приложением / Полный доступ**;
    - вкладка **Аккаунты WhatsApp** → **WABA 1363377080731255** → **Полный доступ**.
    - **Нужны ОБА** назначения, иначе будут ошибки прав (#200/#10) при отправке.
13. **Перезагрузите страницу**, подождите пару минут, пока покажет «Полный доступ» (назначение не мгновенное — если сразу жать «Создать токен», кнопка может быть серой).
14. Нажмите **Generate new token (Создать токен)** → выберите ваше приложение → **Token expiration = Never (Никогда)** → отметьте права:
    - `whatsapp_business_messaging` (отправка/приём),
    - `whatsapp_business_management` (чтение номеров/шаблонов),
    - `business_management`.
    → **Generate**.
15. **Сразу скопируйте токен `EAAG…`** — он показывается **один раз**. Потеряете — придётся выпускать заново.
16. Проверьте токен в **developers.facebook.com/tools/debug/accesstoken/** — должно быть **Expires: Never** и оба whatsapp-права.

### Часть D. Достать phone_number_id и включить приём сообщений

17. Получить **phone_number_id** напрямую (минуя тестовый номер): в браузере открыть
    `https://graph.facebook.com/v22.0/1363377080731255/phone_numbers?access_token=ВАШ_ТОКЕН`
    В ответе поле **`id`** для номера +7708… — это и есть phone_number_id.
18. Подписать приложение на WABA (чтобы **принимать** входящие через вебхук):
    `POST https://graph.facebook.com/v22.0/1363377080731255/subscribed_apps` с этим токеном.
19. Вебхук: App Dashboard → **WhatsApp → Configuration** → указать Callback URL и Verify token вашего бота.

## 3. Запасные пути (по убыванию приоритета)

### Fallback 1 — Быстрый временный токен «прямо сейчас», чтобы проверить связь (5 минут)
**Когда:** хотите за минуту убедиться, что номер вообще доступен вашему приложению, до возни с системным пользователем.
**Шаги:** Часть A → Часть B → скопировать **Temporary access token** (~23 ч) → отправить тестовое сообщение с панели API Setup. Работает — значит основной путь (Часть C) точно даст постоянный токен. **В бота этот токен не ставить.**

### Fallback 2 — Токен через системного пользователя, даже если WABA только расшарена
**Когда:** диагностика (раздел 4) показала, что WABA **видна** у вас, но владелец — другой бизнес (shared-in).
**Почему может сработать:** админ-системный пользователь имеет доступ к WABA, «принадлежащим ИЛИ расшаренным» портфелю. Токен часто выпускается и шлёт на этот номер без владения.
**Шаги:** те же, что Часть C (системный пользователь + оба актива + права), затем смоук-тест: `GET /1363377080731255/phone_numbers`.
- Отвечает нормально → всё, пользуйтесь.
- Ошибка **код 200 / нет прав** → это тот случай, когда без владельца никак → Fallback 3.

### Fallback 3 — Передача владения WABA от старого подрядчика (участие владельца обязательно)
**Когда:** WABA принадлежит другому бизнесу и/или в ответе API заполнено `on_behalf_of_business_info` (старая модель OBO), и Fallback 2 упёрся в ошибку прав.
**Шаги:**
1. Владелец (старый подрядчик/BSP) инициирует **передачу владения (ownership transfer)** на портфель Kazzhol.
2. Вы как **админ Kazzhol**: business.facebook.com/settings → **Requests / Запросы → Полученные → Review/Approve**.
3. После этого поле «Владелец» у WABA станет Kazzhol → возвращаетесь к основному пути (Часть C).
> Кнопки «забрать WABA себе» в одностороннем порядке НЕ существует — толчок делает только текущий владелец.

### Fallback 4 (крайний) — Мигрировать сам НОМЕР +7 708 709 3000 в новую WABA Kazzhol
**Когда:** нужен именно номер, а старую WABA получить не выходит.
**Шаги:** старый владелец **выключает 2FA и удаляет/освобождает номер** из своей WABA → вы в API Setup добавляете номер, запрашиваете код подтверждения, задаёте новый 6-значный PIN 2FA.
> Будет ошибка «номер уже зарегистрирован», пока старая сторона полностью не отпустит номер (иногда несколько минут). Минус: теряется старая WABA и её история/шаблоны.

## 4. Диагностика: заблокированы ли вы владельцем (сделать ПЕРВЫМ делом, 1 минута)

Возьмите любой токен, который видит WABA (хоть временный из Части B), и откройте в браузере:

```
https://graph.facebook.com/v22.0/1363377080731255?fields=id,name,owner_business_info,on_behalf_of_business_info&access_token=ВАШ_ТОКЕН
```

Читаем ответ:
- **`owner_business_info.id` = ID портфеля Kazzhol** → вы **ВЛАДЕЕТЕ** → основной путь (раздел 2) работает.
- **`owner_business_info.id` = другой бизнес**, или заполнено **`on_behalf_of_business_info`** → WABA **чужая/OBO** → сначала Fallback 2, при ошибке прав — Fallback 3/4 (нужен владелец).

Кросс-проверка через интерфейс (без кода): business.facebook.com/settings → **Аккаунты → Аккаунты WhatsApp** → выбрать WABA → поле **«Владелец / Owned by»**. Kazzhol → ваша; другое имя → чужая.

Смоук-тест (самый практичный): выпустили токен → `GET /1363377080731255/phone_numbers`.
- **Успех** → путь открыт.
- **Ошибка код 200 (нет прав)** → WABA не принадлежит вашему приложению → нужен владелец.

## 5. Что именно прислать разработчику

Разработчику самостоятельного бота нужны **две строки**:

| Что | Как выглядит | Где взять |
|---|---|---|
| **Access token** | `EAAG…` (длинная строка, постоянный) | Раздел 2, Часть C, шаг 14–15 (Generate token у системного пользователя, Expiration = Never). Показывается ОДИН раз. |
| **phone_number_id** | числовой ID (например `1234567890`), **это НЕ +7708…** | Раздел 2, Часть D, шаг 17: поле `id` в ответе `/1363377080731255/phone_numbers`. Либо на панели API Setup под номером «Phone number ID». |

Плюс для контекста (обычно уже известно разработчику):
- **WABA ID:** `1363377080731255`
- **Версия Graph API:** `v22.0`
- **Номер (display):** `+7 708 709 3000`

Бот отправляет через `POST /{phone_number_id}/messages`, принимает через вебхук.

## 6. Если владение всё же блокирует всё (честный итог + минимальный запрос владельцу)

Если диагностика показала чужое владение **и** Fallback 2 упёрся в ошибку прав — самостоятельно вы токен **не выпустите**, это ограничение Meta, а не ошибка в шагах. Нужен либо старый подрядчик, либо владелец бизнеса (Бернер).

**Минимальный запрос (одно из двух — просите первое):**

1. **Передать владение WABA** `1363377080731255` на бизнес-портфель Kazzhol (ID портфеля можно взять в business.facebook.com/settings → Business info). Подрядчик инициирует ownership transfer; вы примете в **Requests → Полученные → Approve**. После этого всё делаете сами по разделу 2.

   *или, если WABA отдавать не хотят —*

2. **Освободить номер** +7 708 709 3000: выключить у него двухфакторную защиту (2FA/PIN) и удалить/освободить номер из старой WABA, чтобы вы завели его в свою новую WABA (Fallback 4).

Дополнительно перед отправкой реальным клиентам (не тестовым): к WABA должен быть **привязан способ оплаты** (с 1 июля 2025 Meta берёт плату за шаблонные сообщения), и портфель со временем попросят пройти **Business Verification** — на выпуск токена это не влияет, но всплывёт при масштабировании.
