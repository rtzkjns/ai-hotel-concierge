# План: Kazzhol AI-бот по ТЗ 1 (WhatsApp-first, 4 языка, полный менеджер)

**Spec:** `docs/specs/2026-07-10-tz1-ai-bot.md` (читать первым).
**Goal:** превратить Telegram-скелет в мультиканального AI-менеджера отеля по ТЗ 1.
**Done =** `npm run typecheck && npm test` зелёные, `npm start` поднимает сервер в stub-режиме без внешних кредов, веб-виджет отвечает на сообщение end-to-end, live Exely search смоук проходит с кредами.

## Глобальные ограничения (каждая задача обязана соблюдать)

- TypeScript strict, ESM (`"type":"module"`), Node 20+. Существующий стиль: маленькие модули, DI через параметры-deps, никаких классов-синглтонов кроме Store.
- Новые зависимости РОВНО: `fastify`, `@fastify/websocket`, `@fastify/formbody`, `@fastify/cookie`, `ws` types при нужде. Всё остальное — `node:` builtins. Пароли: `node:crypto` scrypt. НЕ добавлять express/axios/lodash/langchain.
- Секреты только из `.env` (gitignored). НИКОГДА не логировать токены/креды. Все user-facing логи и уведомления персоналу проходят `maskPII()`.
- Тесты vitest рядом в `tests/`, имя `<module>.test.ts`. Тест пишется до реализации, прогоняется на FAIL, потом код. Запрещено править существующий тест ради зелени (кроме задач, явно меняющих контракт — там тест меняется по плану).
- Модель по умолчанию: `claude-sonnet-5` (заменить текущий дефолт).
- Коммит после каждой задачи: `feat(scope): ...` на ветке `tz1-bot`.
- **Divergence rule:** 3 неудачные попытки одного и того же → СТОП, отчёт координатору текстом, не импровизировать.
- Языки везде: RU/KK/EN/ZH. Валюта KZT.
