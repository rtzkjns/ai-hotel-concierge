# Настройки проверки здоровья

Два drop-in, без которых сторож бесполезен. Ставятся один раз на сервере.

## Раз в полчаса, а не раз в сутки

`/etc/systemd/system/kazzhol-health.timer.d/often.conf`

```ini
[Timer]
OnCalendar=
OnCalendar=*:0/30
```

Суточное расписание означает, что авария в 06:05 будет замечена через двадцать четыре часа.
Внешних запросов проверка делает немного, поэтому получасовой шаг ничего не стоит.

## Находка — это не авария

`/etc/systemd/system/kazzhol-health.service.d/exit.conf`

```ini
[Service]
SuccessExitStatus=1
```

Скрипт возвращает `1`, когда НАШЁЛ проблемы, — это его нормальный исход. Без этой строки
systemd помечает службу `failed` при каждом срабатывании, и настоящая поломка самой
проверки теряется среди ложных тревог.

## Что проверка ловит

Токены Instagram и подписку на входящие, авторизацию Exely по трём кабинетам, доступность
Anthropic, запущен ли Caddy, а также по журналу службы — недоставленные ответы гостям и
несовпадения подписи вебхуков. Последние два не видны проверкой токенов: токен жив, а
отправлять запрещено.

Отчёт уходит в Telegram, чат из `STAFF_GROUP_CHAT_ID`. Сейчас это группа «Kazzhol test» —
перед сдачей отелю заменить на дежурную группу.
